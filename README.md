# Raspberry-Pi-5-RFID-Access-System-with-LED-Indicator
A lightweight RFID access-control demo built on Raspberry Pi 5 using the MFRC522 SPI RFID reader and a status LED driven through the modern libgpiod v2 interface. The project reads MIFARE cards, prints their UIDs, flashes a green LED when a known tag is detected, and blinks rapidly for unknown tags on the latest Raspberry Pi OS
